# Juander Admin User Manual

A clear, step-by-step guide for all Admin features. Written in simple English and designed for clean PDF export.

## How To Use This Manual
- Read top-to-bottom if you are new. Each section stands alone.
- Follow numbered steps. Screenshots are marked with placeholders.
- Keep your admin account secure. Log out on shared computers.

## Who This Is For
- System Administrators managing content, users, reviews, and analytics.
- Staff tasked with maintaining the tourist experience and safety.

## Access Requirements
- An Admin account with valid credentials.
- Desktop browser recommended (Chrome, Edge, Firefox, Safari).

## 1. Dashboard
The dashboard gives a quick picture of system activity.

### What You See
- Key stats: total users, admins, reviews, average rating, total sites.
- Recent activity: latest reviews and user actions.
- Quick actions linking to important admin tools.

> Insert picture: [Dashboard overview with stats and recent activity]
> Annotation: add red boxes around stats cards and recent activity list.

### How To Use
1. Open Dashboard from the Admin menu.
2. Review the stats for trends (e.g., average rating changes).
3. Use Quick Actions to jump to “Manage Roles”, “Manage Content”, “Reports”, or “System Logs”.

## 2. User Roles Management
Assign and manage user roles.

### Common Tasks
- Change a user’s role (e.g., Tourist → Admin).
- Search and filter users.

> Insert picture: [User list with role selector]
> Annotation: add red circle around the role dropdown; add text label “Save/Update role”.

### Steps
1. Open User Roles from the Admin menu.
2. Find the user by name or email.
3. Select the new role from the role control.
4. Save the change.
5. Confirm the success notification.

## 3. Content Management
Update tour sites and informational content.

### Common Tasks
- Add a new site (name, description, media, location).
- Edit site details.
- Archive or unpublish outdated content.

> Insert picture: [Content list and “Add Site” form]
> Annotation: add arrows pointing to “Add” button, site fields, and image upload.

### Steps: Add a Site
1. Open Content Management from the Admin menu.
2. Click “Add Site”.
3. Fill in site details: name, description, category, location.
4. Upload an image if available.
5. Save. Confirm success.

### Steps: Edit a Site
1. Open Content Management, then click the site in the list.
2. Update fields as needed.
3. Save. Confirm success.

## 7. Itineraries Management
Create and manage tourist itineraries.

### Common Tasks
- Create an itinerary (name, description, duration, image).
- Select sites to include (order matters).
- Edit or remove itineraries.

> Insert picture: [Itinerary form and site selector]
> Annotation: add arrows pointing to “Add Itinerary” button, site list, duration field.

### Steps: Create an Itinerary
1. Open Itineraries Management from the Admin menu.
2. Click “Add Itinerary”.
3. Enter itinerary name, description, and duration.
4. Upload an image (optional but recommended).
5. Select sites to include.
6. Save. Confirm success.

### Steps: Edit an Itinerary
1. Open Itineraries Management, then select an itinerary from the list.
2. Change details or reorder sites.
3. Save. Confirm success.
