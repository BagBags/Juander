## 1. Homepage
Start your journey and access core features.

### What You See
- Start Tour button
- Quick access to Itineraries, Map, Photobooth, Emergency, Profile
- AI guide icon

> Insert picture: [Homepage hero with Start Tour]
> Annotation: add red circle around “Start Tour”.

### Steps
1. Tap “Start Tour”.
2. On mobile, you will go to your itineraries.
3. On desktop, you will open the interactive map.

## 3. Tour Map
Use the interactive map to navigate.

### Map Controls
- Voice Guidance: enable or disable spoken directions.
- My Location: re-center the map to you.
- Current Destination: open the site details card.
- Transport Mode: choose Foot, Bike, or Car.

> Insert picture: [Map with control buttons]
> Annotation: add red circles around each control; add labels “Voice Guidance”, “My Location”, “Destination Card”, “Transport Mode”.

### Directions Panel
- Previous: go back to the previous site.
- Skip: skip the current site.
- Next: move to the next site.

> Insert picture: [Directions panel at bottom]
> Annotation: add red circles around Previous, Skip, Next.

### Steps
1. Open Tour Map.
2. Choose your transport mode.
3. Follow the route line and instructions.
4. Use Previous/Skip/Next to manage your journey.

## 9. Tips for a Smooth Experience

## 10. Troubleshooting
- If the map does not show your location, check permissions.
- If routes seem off, switch transport mode or re-center.
- If tutorials do not start, check the toggle in Settings.
